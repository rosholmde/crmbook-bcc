CRMbook BCC for Outlook

Add your CRMbook sync address to BCC with one click while writing an email.

Download Outlook installation file

  1. Remove the previous CRMbook BCC add-in, if installed.
  2. Open Outlook add-in management.
  3. Choose My add-ins → Custom Addins → Add a custom add-in → Add from File and select the downloaded XML file.
  4. Compose an email and click Add CRM BCC in the ribbon or Apps menu. Check the BCC field before sending.

Your organization may require an administrator to install custom add-ins.
